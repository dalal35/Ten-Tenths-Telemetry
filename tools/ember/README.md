# Ember baseline harness

Run `node tools/ember/capture.mjs before` before UI changes only. Existing before images cause a refusal. Use `before --measure-only` for measurements without overwriting images; use `pass-a` or `after` for later captures. This local-only harness uses Vite development React, Playwright with DPR 1, reduced motion, disabled screenshot animations and hidden caret. Capture waits for fonts, real parsed telemetry, plots and two animation frames. The fixed configuration is exported by `fixture.mjs` (lap 9 primary, lap 10 comparison, GPS Speed and RPM, distance 30–350 m, cursor established by graph keyboard input).

**All IPC is simulated.** The cached `.tools/advanced-ui/0361.json` supplies the actual native diagnostic session and spatial lap comparison including delta. `.tools/coach-ui/0361.json` supplies actual coach diagnostic output. Both are private ignored inputs; do not commit them. Override their paths using `EMBER_ADVANCED_FIXTURE` and `EMBER_COACH_FIXTURE`. The simulated IPC intentionally rejects unsupported telemetry combinations rather than inventing analysis values. Library captures show the session details dialog. Workspace viewport is the primary chart utilization denominator; `mainWorkspace` and `mainUtilization` are supplemental. Visible row heights are clipped to the workspace and browser viewport.

The DevTools hook counts component updates approximated by changed props/state on committed fibers; it is not React Profiler timing. The interaction check compares canvas DOM identities around cursor keys and theme switching. Axe checks HTML only; canvas requires independent color contrast checks. `contrast.mjs` implements WCAG sRGB relative luminance for opaque colors; composite translucent colors against the actual surface before passing them. Screenshots and local cached inputs are never checked into source control.

Run `node tools/ember/capture.mjs after` for the final six Telemetry captures, then `node tools/ember/verify.mjs` for axe, actual canvas palette/dash readback, stationary cursor theme regression, WCAG token contrast, keyboard/zoom/pan/reset identities, 600×500 control/menu reachability, CDP CVD captures and pixelmatch diagnostics. Verification-only dependencies are isolated: `npm ci --prefix tools/ember --ignore-scripts`. `check-baseline-workflow.mjs` can reproduce the existing workflow suite against starting sources through a test-only Vite transform without changing production files. Do not run baseline measurement/capture commands after UI changes; the frozen JSON/images describe the starting commit.
