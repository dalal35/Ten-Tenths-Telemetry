# UI baseline audit

Captured from the real application shell and components at 1440 × 920 and 600 × 500. Run from the repository root with `node prototypes/premium-ui/scripts/capture-baseline.mjs`. Set `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` if the installed Playwright browser is unavailable. The script starts a loopback Vite server, opens headless Chromium, captures four views at each size, and closes both. It substitutes synthetic session and analysis responses from the website bridge and clears its fictitious video source to show the real video UI without footage. Missing demo exports fall back to the desktop bridge; the capture does not invoke those operations. No recordings are imported. The real uPlot and video components render, but the browser run cannot validate native IPC, media playback or AI inference. Browser and OS rendering can vary.
## Architecture and interaction

The frontend is React/TypeScript on Vite, hosted by Tauri. Navigation is application/workspace state rather than a URL-router dependency. App-level React state, refs and lifecycle queues coordinate the views; there is no separate global-state library in package.json. uPlot owns time/distance traces, custom canvas handles advanced plots, and the track uses the existing spatial view. Video uses HTML/YouTube players behind its source and synchronization controllers. The native bridge remains the boundary for analysis, library storage and inference.

- [App](../../src/App.tsx) coordinates session import, library lifecycle, async analysis, shared cursor, workspace persistence and the Telemetry, Video, Advanced and AI Driving Coach views. [Workspace state](../../src/workspace.ts), [navigation](../../src/workspaceNavigation.ts) and [advanced state](../../src/advancedState.ts) own related transitions and persisted values.
- [Session explorer](../../src/SessionSidebar.tsx) and [preferences](../../src/sessionExplorer.ts) handle library navigation, session operations, laps and comparisons. Theme is a header control; explorer preferences, advanced presets and video settings are in their respective surfaces rather than a single settings page.
- [Plots](../../src/Plots.tsx), [track](../../src/Track.tsx) and [segments](../../src/Segments.tsx) share telemetry context. [Advanced](../../src/Advanced.tsx) and [canvas](../../src/AnalysisCanvas.tsx) provide analysis tools. [Video workspace](../../src/video/VideoWorkspace.tsx) manages sources and synchronization; [Coach](../../src/coach/Coach.tsx) presents evidence and analysis.
- Shared controls and view motion live in [motion](../../src/motion.tsx). Styling is distributed across [styles](../../src/styles.css), [explorer](../../src/explorer.css), [advanced](../../src/advanced.css) and [coach](../../src/coach/coach.css). Reuse existing controls and surface patterns.

## Visual observations

- The desktop telemetry view presents selected laps, overlaid traces and the circuit inspector together. Cyan and amber consistently link each lap to its traces and segment values. The graph toolbar has a relatively quiet visual weight compared with the session summary, while the charts occupy most of the remaining workspace.
- The empty Video view clearly names the missing footage and shows both local-file and YouTube attachment controls, but also exposes synchronization and timeline controls before footage is available. A native interaction check is needed to assess their disabled states and guidance.
- At 600 × 500, the session heading, lap summary, workspace tabs, toolbar and Advanced tool selection fill the initial viewport; the analysis canvas requires scrolling. The collapsed explorer is represented by a small edge control, so its discoverability merits a usability check.
- Small muted labels and metadata appear throughout the sidebar, inspector and control rows. Check legibility and contrast at actual desktop scale, including short windows. The narrow sidebar becomes a compact rail/drawer and the inspector moves beneath the chart at its container breakpoint ([App](../../src/App.tsx), [explorer CSS](../../src/explorer.css)).
- The Coach view puts its fastest lap, modeled status and Analyze control near the top; its single synthetic recommendation leaves substantial unused horizontal space at desktop width. Synthetic output is illustrative, not a validation of coaching quality.
Performance and correctness constraints: preserve mounted plot/canvas/video surfaces and active flags; shared cursor updates plots and track, advanced analysis is debounced, video pauses when inactive, and native workspace changes are serialized. Existing `npm run test:sidebar` checks resize/navigation and non-remount behavior with synthetic IPC. No native recordings, inference, accessibility audit or functional test suite was run for this baseline.
