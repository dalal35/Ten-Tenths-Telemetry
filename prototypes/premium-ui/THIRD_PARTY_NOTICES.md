## shadcn/ui

NativeSelect.tsx adapts the native select wrapper/option structure from shadcn/ui. Tailwind, cn and Lucide styling dependencies were replaced with local CSS and a decorative character; native select semantics remain.

## React Bits

LapTime.tsx adapts the Motion animate/onUpdate/cleanup technique from CountUp, retaining cancellation and reduced motion. The substantial rolling-digit engine, replay, effects, and extra API were omitted. Only user-selected summary times animate; cursor data remains immediate.
Source: https://github.com/DavidHDev/react-bits/blob/main/src/ts-default/TextAnimations/CountUp/CountUp.tsx
